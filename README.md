# E-paper badge — Web App

เว็บสำหรับออกแบบป้ายและส่งเข้า E-paper badge ผ่าน Bluetooth ไม่ต้องติดตั้งอะไร เปิดในเบราว์เซอร์ใช้ได้เลย

- เว็บ: [URL](https://nowaystaynomyarn.github.io/E-Badge-Webapp/) 
- Firmware: [___ลิงก์ repo firmware___](https://github.com/NowayStayNomyarn/E-Badge-Firmware/)

## ทำอะไรได้

- ออกแบบป้าย: ข้อความ 2 บรรทัด, ใส่รูป, เลือกสี ดำ/แดง/ขาว
- ดูตัวอย่างก่อนส่ง แล้วกดส่งเข้าป้าย
- เขียนลิงก์ลงการ์ด NFC
- ดูประวัติ: รูปที่เคยส่ง และลิงก์ที่เคยเขียน (ส่งหรือเขียนซ้ำได้)

## สิ่งที่ต้องมี

- Chrome หรือ Edge บนคอมหรือ Android (iPhone/Safari ใช้ไม่ได้)
- เปิดผ่าน HTTPS หรือ localhost
- ป้ายที่อัปโหลด firmware แล้ว

## วิธีใช้

**ส่งภาพเข้าป้าย**
1. กด **เชื่อมต่อป้าย** แล้วเลือก `E-paper badge`
2. ออกแบบในแท็บ ภาพ / ข้อความ / สี
3. กด **ส่งเข้าป้าย** แล้วรอจอรีเฟรชประมาณ 15 วินาที

**เขียนลิงก์ลงการ์ด NFC**
1. เชื่อมต่อป้ายก่อน
2. ใส่ลิงก์ (ขึ้นต้น `http://` หรือ `https://` ไม่เกิน 100 ตัวอักษร)
3. กด **เขียนลงการ์ด NFC**
4. แตะการ์ดที่เครื่องอ่านบนป้ายภายใน 30 วินาที

ใช้ได้กับการ์ด NTAG213/215/216 เท่านั้น และข้อมูลเดิมในการ์ดจะถูกเขียนทับ

## เทคโนโลยี

HTML, CSS, JavaScript ล้วน ใช้ Web Bluetooth ติดต่อป้าย และเก็บประวัติในเบราว์เซอร์ (localStorage)
