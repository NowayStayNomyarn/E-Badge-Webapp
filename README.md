# E-paper badge — Web App

เว็บสำหรับออกแบบป้ายและส่งเข้า E-paper badge ผ่าน Bluetooth ไม่ต้องติดตั้งอะไร เปิดในเบราว์เซอร์ใช้ได้เลย

- เว็บ: [E-Badge-Webapp](https://nowaystaynomyarn.github.io/E-Badge-Webapp/)
- Firmware: [E-Badge-Firmware](https://github.com/NowayStayNomyarn/E-Badge-Firmware/)

## ทำอะไรได้

- ออกแบบป้าย: ข้อความ 2 บรรทัด (ปรับขนาด/สีได้), ใส่รูป, เลือกสี ดำ/แดง/ขาว
- เลย์เอาต์ 4 แบบ: ข้อความอย่างเดียว, รูปซ้าย + ข้อความขวา, ข้อความซ้าย + รูปขวา, รูปเต็มจอ
- ปรับรูป: ซูม เลื่อนตำแหน่ง (ลากบนพรีวิว/ล้อเมาส์), Dither, Brightness, Contrast, ความไวสีแดง, กรอบ
- ดูตัวอย่างขนาดจริง 296×128 ก่อนส่ง แล้วกดส่งเข้าป้าย
- เขียนลิงก์ลงการ์ด NFC
- ดูประวัติ: รูปที่เคยส่ง และลิงก์ที่เคยเขียน (ส่งหรือเขียนซ้ำได้)
- ส่ง log ขึ้น ThingsBoard (ไม่บังคับ): รูปที่อัปโหลด และลิงก์ที่เขียนลงการ์ด พร้อมเวลา

## สิ่งที่ต้องมี

- Chrome หรือ Edge บนคอมหรือ Android (iPhone/Safari ใช้ไม่ได้ เพราะไม่รองรับ Web Bluetooth)
- เปิดผ่าน HTTPS หรือ localhost
- ป้ายที่อัปโหลด firmware แล้ว

## วิธีใช้

**ส่งภาพเข้าป้าย**
1. กด **เชื่อมต่อป้าย** แล้วเลือก `E-paper badge`
2. ออกแบบในแท็บ ภาพ / ข้อความ / สี
3. กด **ส่งเข้าป้าย** แล้วรอจอรีเฟรชประมาณ 15 วินาที (จอ 3 สีรีเฟรชช้า)

**เขียนลิงก์ลงการ์ด NFC**
1. เชื่อมต่อป้ายก่อน
2. ใส่ลิงก์ (ขึ้นต้น `http://` หรือ `https://` ไม่เกิน 100 ตัวอักษร)
3. กด **เขียนลงการ์ด NFC**
4. แตะการ์ดที่เครื่องอ่านบนป้ายภายใน 30 วินาที

ใช้ได้กับการ์ด NTAG213/215/216 เท่านั้น (MIFARE Classic ไม่รองรับ) และข้อมูลเดิมในการ์ดจะถูกเขียนทับ

**ดูประวัติ**
- แท็บ **ประวัติ** แสดงรูปที่เคยส่ง (กด **ส่งซ้ำ** ได้) และประวัติการเชื่อมต่อ/แตะ NFC/เขียนลิงก์ (กด **เขียนซ้ำ** ได้)
- ประวัติเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (รูปล่าสุด 25 รายการ, ลิงก์ 100 รายการ)

## ส่ง log ขึ้น ThingsBoard (ไม่บังคับ)

1. สร้าง device ใน ThingsBoard แล้วคัดลอก **Device access token**
2. ในแท็บ **ประวัติ** กรอก Host (เช่น `eu.thingsboard.cloud`) และ Token แล้วติ๊ก **ส่ง log อัตโนมัติ**
3. กด **ทดสอบส่ง** แล้วดู telemetry ใน ThingsBoard

## ทดสอบโดยไม่มีป้าย (Wokwi demo)

เลือกโหมด **Wokwi demo (MQTT)** ในการ์ดเชื่อมต่อ แล้วรัน sketch จำลองใน Wokwi ใช้ Device ID เดียวกัน ฟังก์ชันส่งรูป/เขียนลิงก์ทำงานเหมือนโหมด Bluetooth

- จอจำลองเป็นขาว-ดำ (สีแดงแสดงเป็นดำ) และ "แตะการ์ด" ใช้ปุ่มในโปรเจกต์ Wokwi
- ใช้ public broker (`broker.hivemq.com`) ให้ใช้ Device ID สุ่ม และห้ามส่งข้อมูลส่วนตัว

## เทคโนโลยี

HTML, CSS, JavaScript ล้วน ใช้ Web Bluetooth ติดต่อป้าย เก็บประวัติในเบราว์เซอร์ (localStorage) และส่ง log ไป ThingsBoard ผ่าน HTTP (โหมด Wokwi ใช้ MQTT.js ผ่าน WebSocket)
