# E-paper badge — Firmware

โค้ด ESP32-S3 สำหรับ E-paper badge ป้ายจอ e-ink 3 สี (ดำ/แดง/ขาว) ขนาด 2.9" ที่มี NFC

- รับภาพจากเว็บแอปผ่าน Bluetooth (BLE) แล้วแสดงบนจอ
- อ่านการ์ด NFC และส่ง UID กลับไปที่เว็บ
- เขียนลิงก์ลงการ์ด NFC ตามที่เว็บสั่ง

Web app: ___ลิงก์ repo เว็บ___

## อุปกรณ์

- ESP32-S3-WROOM-1 (N16R8)
- จอ e-paper 2.9" 296×128 3 สี (SSD1680)
- PN532 (NFC, ต่อแบบ I2C)
- ไฟจากแบต AA 4 ก้อน หรือ USB

## Pin

| อุปกรณ์ | ขา |
|---|---|
| PN532 SDA / SCL | GPIO 5 / 6 |
| จอ BUSY / CS / DC / RES | GPIO 9 / 10 / 11 / 12 |
| จอ SDI / SCLK | GPIO 13 / 14 |

แก้ได้ที่ส่วน `Pins` ต้นไฟล์ `src/main.cpp`

## วิธีอัปโหลดลงบอร์ด

1. ติดตั้ง VS Code + PlatformIO แล้วเปิดโฟลเดอร์นี้
2. ต่อสาย USB เข้าบอร์ด
3. กด **BOOT** ค้าง → กด **EN** → ปล่อย **BOOT**
4. กด Upload
5. กด **EN** หนึ่งครั้ง แล้วเปิด Serial Monitor (115200) จะเห็น `Advertising as E-paper badge`

## วิธีทำงาน

1. บอร์ดเปิด Bluetooth ชื่อ `E-paper badge`
2. เว็บเชื่อมต่อแล้วส่งภาพมา (ชั้นดำ + ชั้นแดง รวม 9,472 ไบต์ บิต `1` = มีหมึก)
3. บอร์ดวาดภาพลงจอ (ใช้เวลาประมาณ 15 วินาที)
4. เมื่อมีการแตะการ์ด NFC บอร์ดส่ง UID ไปให้เว็บ
5. ถ้าเว็บสั่งเขียนลิงก์ บอร์ดรอแตะการ์ดไม่เกิน 30 วินาที แล้วเขียนลงการ์ด (ใช้ได้กับการ์ด NTAG213/215/216 เท่านั้น)

## ข้อมูลที่คุยกับเว็บ (BLE)

Service UUID: `7a1c0001-5b7e-4c1a-9d2e-0a1b2c3d4e5f`

| ชื่อ | UUID ขึ้นต้น | ทำอะไร |
|---|---|---|
| ctrl | `7a1c0002` | เว็บสั่งเริ่มส่ง (`0x01`) / ส่งครบแล้ว (`0x02`) |
| data | `7a1c0003` | เว็บส่งข้อมูลภาพเป็นชิ้น ๆ |
| stat | `7a1c0004` | ป้ายแจ้งสถานะ: 0 พร้อม, 1 กำลังรับ, 2 วาดเสร็จ, 3 ผิดพลาด, 4 รอแตะการ์ด, 5 เขียนการ์ดสำเร็จ, 6 เขียนการ์ดไม่สำเร็จ |
| nfc | `7a1c0005` | ป้ายส่ง UID ของการ์ดที่แตะ |
| link | `7a1c0006` | เว็บส่ง URL ที่จะเขียนลงการ์ด (ส่งค่าว่าง = ยกเลิก) |

## ถ้าเจอปัญหา

| อาการ | วิธีแก้ |
|---|---|
| จอว่างหรือภาพเพี้ยน | เปลี่ยนไดรเวอร์เป็น `GxEPD2_290_Z13c` และเช็ค pin จอ |
| ภาพกลับหัว | เปลี่ยน `setRotation(1)` เป็น `3` |
| `PN532 not found` | ตั้งสวิตช์บนโมดูลเป็นโหมด I2C และเช็คสาย |
| เขียนการ์ดไม่สำเร็จ | ต้องเป็นการ์ด NTAG (MIFARE Classic ไม่รองรับ) |
| ไม่เจอพอร์ต USB | เข้าโหมด download ใหม่ และใช้สายที่ส่งข้อมูลได้ |
